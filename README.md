# 🎨 beat-painter

> Pinta con tu voz. Canta, tararea o haz ruido — el micrófono convierte el sonido en arte.

**beat-painter** es una PWA para niños donde el sonido se convierte en arte visual en tiempo real. Cada modo de pintura reacciona de forma distinta al volumen, los graves, los medios y los agudos.

## Modos de pintura

| Modo | Qué hace |
|---|---|
| 🫧 Burbujas | Círculos que crecen con el volumen |
| 〰️ Ondas | Ondas sinusoidales que vibran con la voz |
| ⭐ Estrellas | Estrellas que se dispersan con los agudos |
| 🌸 Pétalos | Flores que rotan con los graves |
| 🌧️ Lluvia | Gotas que caen más rápido cuando hablas |
| 🌌 Galaxia | Espiral de partículas que gira con el volumen |
| 🌋 Lava | Blobs lentos y pesados que se mueven con los graves |

## Paletas

- **Neón** — colores vivos y saturados
- **Pastel** — suaves y delicados
- **B&N** — blanco y negro
- **Atardecer** — rojos, naranjas y amarillos

## Tech stack

React 18 · TypeScript · Vite · Tailwind CSS · Web Audio API · Canvas 2D · Zustand · PWA

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy

GitHub Actions → GitHub Pages automático en cada push a `main`.
